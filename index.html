Lock Guard test pages

Load dist/ unpacked at chrome://extensions first. Each link opens in a new tab, so this page stays open.

Provided with the assignment

  • Scam malicious.html Expected: the tab closes and an explanation page opens.
  • Legitimate benign.html Click "View Generated Report". Expected: the report opens and stays open.

Harder cases

  • Scam malicious-layers.html Extra traps: capture-phase key blocking, history stuffing, and full screen after a click. Expected: closed.
  • Scam malicious-delayed.html Looks harmless, then becomes a lock screen after 3 seconds. Expected: closed once it changes.
  • Legitimate benign-editor.html Click "Open message". A mail view showing scam text, with an unsaved-reply guard. Expected: stays open.

Beyond the lock screen

  • Scam malicious-image.html The whole message is a picture, so there is no text to read. Expected: closed, on a site this browser has not visited before.
  • Legitimate benign-fullscreen.html Click "Open deck", then "Full screen". Expected: the deck goes full screen and stays open.
  • Scam malicious-download.html Click "Download support tool". Expected: a notice opens with a "Delete the file" button; the file is untouched until you press it. The PDF button is the control: no notice.
  • Scam malicious-dialogs.html An endless run of alert boxes. Press OK five times. Expected: the run is cut and the page is closed.

After Lock Guard closes a lock-screen page, opening a remote-control site such as anydesk.com within 30 minutes shows a warning first.
